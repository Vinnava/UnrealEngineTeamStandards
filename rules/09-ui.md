# 12. UMG and Slate rules

Part of the [Unreal Engine Team Standards](../README.md). Section numbers are global; the reasoning
is in [why.md](../why.md).

---

### 12.1 BindWidget

- `meta = (BindWidget)` matches on **object name**, case-insensitively, and is a **hard compile
  requirement** - the Blueprint will not compile if the widget is missing.
- `meta = (BindWidgetOptional)` is the soft form.
- A widget may move anywhere in the tree as long as its **name survives**. A rename breaks the bind.
- Bind names: 7.4.

### 12.2 Widget structure

- **Use the right panel.** `Overlay` stacks; side-by-side children need a `HorizontalBox`.
- **Strip wrapper hierarchy** - a single-child `Overlay` or `ScaleBox`, a `ScaleBox` around an
  already-fixed-size `SizeBox`, a `Spacer` where slot padding would do, a `RenderTransform` scale where
  a brush `ImageSize` would do.
- **Turn the `bOverride_*` flag on** for every overridden value; without it the value is inert.
- **Name by role, never by engine default.** `headerTitle_Text`, not `TextBlock_45` (7.4). Set `Name`
  and `DisplayLabel` to the same string.
- **One widget, one job.** A widget that both fetches and displays is two widgets.

### 12.3 T3D pastes

When exchanging widget trees as T3D text between developers:

- Apply 12.2 before sending - a paste-ready tree, not a dump.
- **Preserve every `BindWidget` name exactly.**
- **State that the old root must be deleted before pasting** - UMG suffixes duplicates (`back_Btn_1`)
  and breaks every bind.
- **Flag layout bugs you find on the way** rather than quietly fixing them.

### 12.4 Slate

- **Never resolve layout by walking an engine widget's `GetChildren()`.** Use the published
  `SLATE_ATTRIBUTE` / `SLATE_ARGUMENT`, the style struct, or subclass and override the virtual
  (section 16).
- **Check whether the engine widget already implements the input hook** before overriding it. One
  owner per input.

### 12.5 Player-facing text

- **Everything a player reads is `FText`**, never `FString` or `FName`.
- **C++ literals use `LOCTEXT` / `NSLOCTEXT`**, with `LOCTEXT_NAMESPACE` defined and undefined inside
  the `.cpp`. In Blueprint and assets, leave player-facing text localisable, not culture-invariant.
- **Never `FText::FromString` on player-facing text.** Use `LOCTEXT` or a string table.
- **Build sentences with `FText::Format` and named arguments**, never by concatenation.
- **Numbers, dates, times, percentages and money go through `FText::AsNumber`, `AsDate`, `AsTime`,
  `AsPercent`, `AsCurrency`, `AsTimespan`** - never formatted by hand.
- **Never hard-code a key name in text** - show the current binding's glyph (`UCommonActionWidget`).
- **Wire and save data stay `FString`.** Convert at the UI boundary.
- **`FName` for identity** (map keys, bones, sockets, tags); **`FString` for manipulation** (paths,
  parsing, logs); **`FText` for anything a player reads.**

### 12.6 UI architecture and cost

**A widget displays. It never owns, decides or polls.** The test: delete every widget, and the game is
still fully playable and correct.

- **UI is client-only**, owned by the PlayerController or a `ULocalPlayerSubsystem` - never the pawn.
- **Lifecycle:**
  - `NativeOnInitialized` - one-time setup.
  - `NativePreConstruct` - appearance only; guard editor-only work with `IsDesignTime()`.
  - `NativeConstruct` - bind, and **seed the initial value**.
  - `NativeDestruct` - unbind, mirroring Construct exactly.
  - `NativeTick` - don't.
- **Update by push, not pull.** No UMG property bindings and no `NativeTick` polling. Push with a
  delegate on change, or use a view model (MVVM, `FieldNotify`) - introduce one when the third widget
  needs the same value.
- **Screens are pushed, not opened.** With Common UI: set the Game Viewport Client class to
  `CommonGameViewportClient`, give every activatable widget a desired focus target
  (`NativeGetDesiredFocusTarget`), and push screens onto layer stacks through a subsystem.
- **Widget count is the cost:**
  - Toggle with `Collapsed`, not `Hidden`.
  - Non-interactive widgets are `HitTestInvisible` or `SelfHitTestInvisible`.
  - List views recycle their entries.
  - `InvalidationBox` only around static content.
  - Project world-space widgets to a screen canvas where you can - each is its own render target.
- **Budget the HUD** (a project number - 0.5 ms is typical) and measure with `stat slate` and the
  Widget Reflector.
